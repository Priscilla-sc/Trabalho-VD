# Trabalho-VD
Trabalho da disciplina de visualização de Dados do Mestrado em Ciência da Computação da UFCIRJ (CEFET-RJ).

## Objetivo
Apresentar o fluxo utilizado para execução das analises do trabalho da disciplina: carregar o conjunto de dados, configurar o método usado no R, executar a análise e interpretar os resultados e gráficos obtidos.


## Base de dados:

A1Benchmark                    Yahoo Webscope S5 – A1 Benchmark (Real)
A2Benchmark                    Yahoo Webscope S5 – A2 Benchmark (Synthetic)
A3Benchmark                    Yahoo Webscope S5 – A3 Benchmark (Synthetic with Outliers)
A4Benchmark                    Yahoo Webscope S5 – A4 Benchmark (Synthetic with Anomalies and
                               CPs)
